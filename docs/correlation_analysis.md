## 3. 核心结论

1. **纳指是 4 资产的最佳补充**: 个体指标最强 (CAGR 19%), 与 A 股相关性最低 (0.12-0.27)
2. **标普 500 应排除**: 与纳指相关性 0.56 (中-高, 同涨同跌明显); 2022 单年深跌拖累组合
3. **黄金是真分散器**: 与其他 3 资产相关性都 < 0.20; 通胀对冲独立性强
4. **红利 / 可转债是债性双胞胎**: 相关性 0.53, 风险事件同跌; 整体作为防守压舱石
